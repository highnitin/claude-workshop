Be Clear and Specific

Small prompt changes create massive output differences — precision is the first skill to master.

WHY
Small changes, massive impact
Every word in your prompt shifts Claude's output. Vague instructions produce generic answers. Specific instructions produce precise, immediately useful results. This single principle underlies every other technique in this course.
WHAT
Three rules for clarity
• State your task first — put the main request in the opening line

• Provide context and details — audience, purpose, constraints, format

• Break complexity down — split large tasks into clear, ordered steps
HOW
Specify the who, what, why
Include the number of slides, the meeting purpose, the topics to cover, and the requested output format — all in one focused prompt. Nothing vague, nothing assumed.
NOW
Your action step
Find a prompt you use regularly. Add: the specific number of items, the purpose, the audience, and the desired format. Send it and notice the difference in output quality.
Prompt Comparison — See the Difference
✕ Weak Prompt
"Help me with a presentation."
✓ Effective Prompt
"I need help creating a 10-slide presentation for our quarterly sales meeting. The presentation should cover our Q2 sales performance, top-selling products, and sales targets for Q3. Please provide an outline with key points for each slide."
Why it's better: The effective prompt provides specific details — the number of slides, the meeting's purpose, and the exact topics to be covered — giving Claude a precise target. The weak prompt could result in anything: a random structure, wrong topics, or a format unsuited for business.
